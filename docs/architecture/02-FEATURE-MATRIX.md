*This table is a proposal to reconcile prior discussions. Do not treat Pro as a requirement for using one's own local AI model where supported. No watermark anywhere, including trial projects and imported templates except third-party media carrying its own protected marks.*

## Distinctive UX, without AI pressure
Use smart deterministic defaults; advanced style variations show unobtrusively under `More`. An ordinary user should see Media → Text → Transitions → Audio → Export, not an AI dashboard. Offer AI tools only when relevant (e.g. when user chooses `Extend canvas`), labeled with offline/cloud badges and pricing/consent. Make all operations reversible.
